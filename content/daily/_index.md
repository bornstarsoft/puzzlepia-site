Puzzlepia's daily puzzle area is the place for quick, friendly brain breaks. These starter puzzles are simple HTML5 prototypes designed to grow over time.

Choose a puzzle below, or start with [Daily Block Puzzle](/daily/block-puzzle/) if you want a good first pick. After the quick starter, you can explore the related [Blockzzle](/games/blockzzle/) game page.

For a related daily Sudoku puzzle, [Play DaySudoku](https://daysudoku.com/), a free daily Sudoku puzzle with a Key9 twist. Find the Key9 first, then finish the full Sudoku.

More starter daily puzzles will be added gradually while the current set stays quick and easy to revisit.
