## Round 1: find the first four

Before tapping, find **1, 2, 3 and 4** on this board. Which four positions will you use, in that order?

The large numbers are the values to find. The small position labels count cells from left to right, starting at the top. This is a fixed reading exercise using the actual **Layout 1** from Daily Number Puzzle, not an interactive board.

{{< number-order-example layout="1" >}}

{{< puzzle-reveal title="Show a small hint" >}}
Find 1 in the top row. Then scan each row for 2 before looking for 3 and 4. The next number does not need to be beside the previous one.
{{< /puzzle-reveal >}}

{{< puzzle-reveal title="Show the positions and explanation" >}}
The values are **1, 2, 3, 4**. Their positions are **2, 9, 6, 4**:

- **1**: top row, second column, position 2.
- **2**: third row, first column, position 9.
- **3**: second row, second column, position 6.
- **4**: top row, fourth column, position 4.

Ascending order applies to the large numbers, not the position labels. There is no connected path to draw. After 4, look for 5 and continue through 16 to finish the playable puzzle.
{{< /puzzle-reveal >}}

## Try it on the same board

[Play Number Puzzle: Layout 1](/daily/number-puzzle/?layout=1). Tap the first four values in order, then finish at 16. Reset restores all tiles on this same layout, including after completion. There is no timer or saved progress.

## Your three-round practice

1. **Quick Number Focus**: locate the first four values.
2. [Number Order: 1 to 10](/daily/challenges/number-order-1-to-10/): cross from one digit to two.
3. [Find the Final Four Numbers](/daily/challenges/find-the-final-four-numbers/): finish a different board.

Choose any round for a later break; the questions stay the same. Read [Number Puzzle Warmups](/blog/number-puzzle-warmups-for-casual-players/) for scanning ideas, or explore the [Games](/games/) hub for related Puzzlepia game pages.
