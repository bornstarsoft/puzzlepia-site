Try two small questions with different goals: follow a word in a straight line, then find every tile of one color. Do either round now and keep the other for your next break. There is no timer or need to finish both together.

These are fixed reading puzzles, not newly generated weekend boards. Each round links to the matching playable game below.

## Round 1: find PLAY {#word-round}

Find **PLAY** from left to right in the First steps board. Which row contains the complete word, and which column does it start in? Some other rows contain part of the word, so check all four letters before choosing.

{{< word-search-example set="starter" >}}

{{< puzzle-reveal title="Round 1: show a small hint" >}}
Look in the lower half of the board. The correct row begins with P. Seeing LAY elsewhere is not enough: the letter before it must be P.
{{< /puzzle-reveal >}}

{{< puzzle-reveal title="Round 1: show the answer" >}}
**Row 5, columns 1 to 4** spells **P L A Y**. Start at P in column 1 and finish at Y in column 4. Row 2 begins U L A Y, so it does not spell PLAY.

The useful check is the whole sequence, not just a familiar ending. In Word Search the letters must form one straight, unbroken line.
{{< /puzzle-reveal >}}

[Play the First steps Word Search set](/daily/word-search/?set=starter). Tap the first P and final Y, or drag between them. Finding PLAY finishes this reading round; the playable game asks for **STAR, MOON, MINT and PLAY** before its completion message appears.

## Round 2: find every purple tile {#color-round}

Count every **Purple** tile on the Color Match board. How many are there, and which row has none? Use the color names as well as the fills. Position numbers run left to right, then down to the next row.

{{< color-match-example >}}

{{< puzzle-reveal title="Round 2: show a small hint" >}}
Start with the top row, even if its count is zero. Then make a separate count for each remaining row so you do not count a tile twice.
{{< /puzzle-reveal >}}

{{< puzzle-reveal title="Round 2: show the answer" >}}
There are **seven** purple tiles, at positions **6, 11, 12, 19, 20, 24, 25**. The row counts are **0, 1, 2, 2, 2**, so **row 1** has none.

This goal differs from the word round. Purple tiles do not need to make a line or one connected group: every tile with the target color counts.
{{< /puzzle-reveal >}}

[Play Color Match: Purple](/daily/color-match/?target=purple). Tap every purple tile in any order. Other colors stay on the board. Reset restores the tiles and keeps purple selected; the round has no timer or score.
