## Puzzle prompt

**Ring practice: 2 of 3.** Start here or use [Ring Size Practice](/daily/challenges/ring-size-practice/) for a one-cell warmup.

Place all three tray rings: **small gold, medium pink, and large mint**. Each cell holds at most one small, one medium, and one large ring. Existing rings stay in place; there are no matches or clears in this exercise.

Cell A already holds a small pink ring and a large mint ring. Cell B holds small mint and medium gold. Cell C holds medium pink and large purple. Dashed outlines show empty positions; the size and color labels below each cell describe the same board in words.

{{< ring-practice-board id="three-spaces" >}}

Which cell receives each ring? Use the sizes, not just the colors, to decide.

{{< puzzle-reveal title="Hint" >}}

Each cell has exactly one empty size. Write down the missing size in A, then B, then C. An existing ring of the same color does not make an occupied size available.

{{< /puzzle-reveal >}}

{{< puzzle-reveal title="Answer and explanation" >}}

- **Medium pink goes in A.** Its small and large positions are occupied, leaving only medium.
- **Large mint goes in B.** Its small and medium positions are occupied, leaving only large.
- **Small gold goes in C.** Its medium and large positions are occupied, leaving only small.

All three rings fit, and every cell now holds three different sizes. The assignment is unique because each tray size has only one compatible cell. You can place the rings in any order.

{{< /puzzle-reveal >}}
