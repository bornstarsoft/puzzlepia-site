**Ring practice: 1 of 3.** Read one cell first, then try a full tray and a shared-cell choice. Each round also works on its own.

## Puzzle prompt

Cell A already has a **small mint ring** and a **large pink ring**. Each cell holds at most one small, one medium, and one large ring. Existing rings stay in place. Nothing matches or clears in this fixed exercise.

{{< ring-practice-board id="one-cell" >}}

Solid rings are occupied sizes; a dashed ring is empty. The size and color names below the diagram describe the same cell.

Can you place a **medium gold ring** in A? What about a second **small ring**, even if it has a different color?

{{< puzzle-reveal title="Hint: find the empty size" >}}
Read the three size positions separately. Which one is empty? Color does not make an occupied size available.
{{< /puzzle-reveal >}}

{{< puzzle-reveal title="Answer and explanation" >}}
The **medium gold ring fits in A** because its medium position is empty. Small mint, medium gold, and large pink can share the cell: their sizes are different.

A second **small ring cannot fit**. The mint ring already occupies that size, regardless of the new ring's color. After placing medium gold, A has no empty size positions left.
{{< /puzzle-reveal >}}
