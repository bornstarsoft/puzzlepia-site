This prompt is a tiny color scanning warmup.

## Puzzle prompt

Look at this row:

`Mint  Pink  Mint  Gold  Mint`

How many mint cells are there?

## Hint

Scan once from left to right, then count only the cells labeled `Mint`.

## Answer

There are three mint cells.

## Play next

Try [Daily Color Match with a mint target](/daily/color-match/?target=mint). The playable board has six mint tiles, unlike the three in this short row exercise. Clear all six in any order; reset keeps the mint target and starts the same board fresh. Then visit [Mapdoku](/games/mapdoku/) for a related BornstarSoft game page.
