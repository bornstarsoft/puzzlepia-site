## Round 2: find the scattered mint tiles

Find all the **Mint** tiles. Which one is separated from the other mint tiles by a full row with no mint?

Use the color names as well as the fills. The small position labels count cells from left to right, top to bottom. This is a fixed reading exercise using the actual Color Match board, not an interactive table.

{{< puzzle-reveal title="Show a small hint" >}}
The fourth row contains no mint tiles. Check below it before you stop scanning.
{{< /puzzle-reveal >}}

{{< puzzle-reveal title="Show the positions and explanation" >}}
There are **six** mint tiles, at positions **3, 8, 9, 14, 15, 23**.

Position **23** is in the bottom row, separated from the others by the mint-free fourth row. Row counts are **1, 2, 2, 0, 1**. You still need that last tile: Color Match asks for every tile of the target color, not just one connected group.

## Try it on the same board

[Play Color Match: Mint](/daily/color-match/?target=mint). Find all six mint tiles in any order. A wrong-color tap leaves the board unchanged. Reset restores every tile and keeps mint selected. The link opens a fresh board; there is no timer or saved progress.

1. [Pink Color Match Challenge](/daily/challenges/pink-color-match-challenge/): scan row by row.
