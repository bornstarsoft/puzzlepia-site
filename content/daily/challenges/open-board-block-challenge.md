## Puzzle prompt

You have three pieces: a **horizontal three-block line**, a **2x2 square**, and a **single block**. Place all three on the empty cells below. Do not rotate the line, overlap pieces, or go outside the board. Nothing moves or clears in this fixed exercise.

**X** means occupied; a **dot** means empty. Columns run A to D and rows run 1 to 4.

{{< block-practice-board id="tray" >}}

Where does each piece belong? As a first move, can you put the single block in the empty corner **A1** and still finish?

{{< puzzle-reveal title="Hint: reserve a shape, not just a cell count" >}}
The line needs three empty cells in one row. The square needs two adjacent rows with the same two empty columns. Find those spaces before choosing a home for the single block.
{{< /puzzle-reveal >}}

{{< puzzle-reveal title="Answer and placement order" >}}
The pieces fit like this:

- Line: **A1, B1, C1**, starting at **A1**.
- Square: **B3, C3, B4, C4**, starting at **B3**.
- Single block: **D2**.

Each empty cell is used exactly once. Only row 1 offers three consecutive empty cells. Only the lower B/C area offers a complete 2x2 space. That leaves D2 for the single block.

Putting the single block at **A1** is legal, but it removes the only line placement. You cannot finish the tray afterward. A corner is not automatically the safest place.

You can place the three pieces in any order **if you keep these positions**. Placing the larger shapes first is a useful planning habit here, not a required rule. A single block at D2 first also works.
{{< /puzzle-reveal >}}
