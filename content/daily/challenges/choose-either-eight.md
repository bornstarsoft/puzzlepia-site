## Round 2: one number, two possible partners

Start with the **2 at position 1**. Which 8 can you match with it: the one at **position 3**, or the one at **position 9**? Can you choose either and still finish the board?

The large numbers are values. The small labels identify positions, counted left to right. Partners do not need to touch. This is a fixed practice board from Make 10, not a timed challenge.

{{< number-pairs-example layout="2" >}}

{{< puzzle-reveal title="Show a small hint" >}}
Find the second 2. After you remove one 2 and one 8, which numbers remain for the next pair?
{{< /puzzle-reveal >}}

{{< puzzle-reveal title="Show the answer and explanation" >}}
The second 2 is at **position 12**. You can choose either:

- Positions **1 + 3**, then **12 + 9**.
- Positions **1 + 9**, then **12 + 3**.

In both routes, each pair uses values **2 + 8 = 10**. The other six pairs can be **2 + 7** (5 + 5), **4 + 10** (1 + 9), **5 + 8** (6 + 4), **6 + 11** (3 + 7), **13 + 14** (4 + 6), and **15 + 16** (3 + 7). Every position is used once.

There is no hidden preferred partner. Correct pairs leave balanced partners behind because this game has no path or adjacency restriction.
