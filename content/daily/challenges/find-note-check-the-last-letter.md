Find **NOTE** on the A little music board. Two straight paths begin **N O T**. Which one finishes with **E**?

- **Path A:** from row 5, column 1, read upward.
- **Path B:** from row 6, column 6, read left.

Read four neighbouring letters in one direction. Rows count from the top; columns count from the left.

{{< puzzle-reveal title="Show a small hint" >}}
Both paths start correctly, so skip ahead to the fourth cell. Compare row 2, column 1 with row 6, column 3.
{{< /puzzle-reveal >}}

{{< puzzle-reveal title="Show the NOTE path" >}}
**Path B spells NOTE**, along **row 6, columns 6 to 3**. Path A reads **N O T A** from bottom to top. It matches the first three letters but ends with A instead of E.

Before choosing your second endpoint, check the whole word. A familiar start is a good lead, not a confirmed match.
