Find **PEAR, LIME, PLUM and KIWI** on the same 6x6 board used by the playable Fruit bowl set. Try one word during a short break, or find all four. Each word follows neighbouring letters in a straight line; do not skip cells or turn a corner.

Choose a question to revisit: [PEAR](#find-pear), [LIME](#find-lime), [PLUM](#find-plum) or [KIWI](#find-kiwi). These section links return to the same question, not saved progress.

## Fruit bowl board

Rows count down from the top; columns count across from the left. Give the start and end coordinates for each word. This table is for reading; use the game link below to select letters.

## Find PEAR

Find a P with room for three more letters below it. Does the whole path spell PEAR?

{{< puzzle-reveal title="PEAR hint" >}}
Look at the rightmost column. The P in the top row has E directly underneath it.
{{< /puzzle-reveal >}}

{{< puzzle-reveal title="PEAR answer" >}}
**Row 1, column 6 to row 4, column 6**: P, E, A, R. Stay in column 6 and move down one row at a time. The P at row 1, column 2 begins a different fruit word.
{{< /puzzle-reveal >}}

## Find LIME

There is more than one L on the board. Check the next letter before choosing a direction.

{{< puzzle-reveal title="LIME hint" >}}
Start with the L in the top row and look down its column. The next letter must be I, not U.
{{< /puzzle-reveal >}}

{{< puzzle-reveal title="LIME answer" >}}
**Row 1, column 4 to row 4, column 4**: L, I, M, E. The L at row 2, column 2 has U below it, so that downward path does not spell LIME. A matching first letter is only a starting clue.
{{< /puzzle-reveal >}}

## Find PLUM

Return to the other P in the top row. Follow all four letters, including the final M.

{{< puzzle-reveal title="PLUM hint" >}}
Use column 2. Read downward from the P, without moving toward the M in another column.
{{< /puzzle-reveal >}}

{{< puzzle-reveal title="PLUM answer" >}}
**Row 1, column 2 to row 4, column 2**: P, L, U, M. PEAR, LIME and PLUM all run downward on this particular board. That does not tell you the direction of the remaining word.
{{< /puzzle-reveal >}}

## Find KIWI

One word remains. Try a different scanning direction and remember that KIWI contains two separate I cells.

{{< puzzle-reveal title="KIWI hint" >}}
Begin with K at the right end of the bottom row. Read left, keeping the W between the two I letters.
{{< /puzzle-reveal >}}

{{< puzzle-reveal title="KIWI answer" >}}
**Row 6, column 6 to row 6, column 3**: K, I, W, I. Columns decrease from 6 to 3 while the row stays 6. Read the complete word from K; do not stop at the first I or reuse one cell.
{{< /puzzle-reveal >}}
