## Which starting cell fits?

Daily Block Puzzle's **Corner** has one cell on top and two below, extending to the right. It cannot rotate. On this empty 6x6 board, compare these starting cells:

- **A: row 5, column 5**.
- **B: row 6, column 5**.

Which start keeps all three cells inside the board? Name the three cells the valid placement covers. Rows count from top to bottom; columns count from left to right. The start is the top-left occupied cell of the piece.

This is a fixed reading diagram, not an interactive board. Both proposed starting cells are empty; check the rest of the shape before deciding.

{{< puzzle-reveal title="Show a small hint" >}}
The Corner reaches one row below its start and one column to the right. Row 6 is the last row.
{{< /puzzle-reveal >}}

{{< puzzle-reveal title="Show the answer and cells" >}}
**A: row 5, column 5** fits. It covers **row 5, column 5; row 6, column 5; row 6, column 6**.

**B: row 6, column 5** does not fit. Its bottom two cells would need row 7, outside the board. The game rejects the whole placement; it does not place just the part that fits.

This answers a boundary question, not a general rule that corners always make the best move.
{{< /puzzle-reveal >}}

## Try it in the game

Open [Daily Block Puzzle](/daily/block-puzzle/) and select Corner. Try row 6, column 5 first: the board should stay empty. Then tap row 5, column 5 to place it.

One placed piece does not finish the game. Place Line 3 at row 1, column 1 and Square at row 3, column 1 to complete this example. There is no line clearing or scoring in the starter. Reset puzzle restores the empty board and all pieces so you can try again.
