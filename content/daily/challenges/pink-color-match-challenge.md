## Round 1: scan for pink

Find every **Pink** tile on this board. How many are there, and which positions contain them?

Use the color names as well as the fills. The small position labels count cells from left to right, top to bottom. This is a fixed reading exercise using the actual Color Match board, not an interactive table.

{{< puzzle-reveal title="Show the positions and explanation" >}}
There are **six** pink tiles, at positions **1, 2, 7, 16, 21, 22**.

Row by row, the counts are **2, 1, 0, 1, 2**. Notice position 7 away from the bottom-left cluster. In the playable puzzle, targets do not need to touch each other; any order works.

## Try it on the same board

[Play Color Match: Pink](/daily/color-match/?target=pink). Find all six pink tiles in any order. A wrong-color tap leaves the board unchanged. Reset restores every tile and keeps pink selected. The link opens a fresh board; there is no timer or saved progress.

## Your three-round practice

1. **Pink Color Match Challenge**: scan row by row.
2. [Mint Color Match](/daily/challenges/mint-color-match/): notice a separated target.
3. [Color Match: Gold Target](/daily/challenges/gold-color-target/): check the middle and the edges.

Choose another round for a later break; these questions stay the same. Read [Color Puzzle Strategy Basics](/blog/color-puzzle-strategy-basics/) for more scanning ideas, or explore [Color Rings Mania](/games/color-rings-mania/) for a related BornstarSoft game page.
